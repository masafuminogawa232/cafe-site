# COZY COFFEE

架空のカフェ「COZY COFFEE」をテーマにしたWebサイトです。

## 制作概要

- **担当範囲:** 企画 / デザイン / 素材生成 / コーディング
- **制作期間:** 約〇日（〇時間）

## 作品背景

「日常の中で、ほっと一息つける時間」をコンセプトに制作しました。

忙しい日々を過ごす人が、コーヒーの香りや落ち着いた空間を感じながら、
気軽に訪れてみたいと思えるカフェサイトを目指しています。

コーヒーや植物の写真を大きく使用し、カフェの穏やかな雰囲気を視覚的に表現しました。
白を基調とした余白のあるレイアウトに、ブラウンとグリーンを組み合わせることで、
清潔感と温かみを両立しています。

## 制作目的

カフェの雰囲気やこだわり、メニュー、店舗情報をわかりやすく伝え、
初めて訪れるユーザーにも安心感を持ってもらえるサイトを制作しました。

ユーザーが必要な情報へ迷わずたどり着けるように、
「ABOUT」「MENU」「ACCESS」の各セクションを設けています。

## デザインコンセプト

### 一杯のコーヒーから始まる、穏やかなひととき

落ち着いた色合いと余白を活用し、実際のカフェにいるような居心地のよさを表現しました。

- **トップページ:** コーヒーや植物の写真を背景に使用し、サイトを訪れたユーザーにカフェの雰囲気が伝わるようにしています。
- **メニューセクション:** 商品写真・商品名・価格をカード型で整理し、目的の商品を直感的に確認できるレイアウトにしました。

## 主なページ・セクション

- **HOME**
  - カフェのコンセプトを紹介
  - メインビジュアルを掲載
- **ABOUT**
  - カフェのこだわりを紹介
- **MENU**
  - コーヒー、ラテ、スイーツなどの商品を掲載
  - 商品名と価格を表示
- **ACCESS**
  - 住所、最寄り駅、営業時間、定休日を掲載
  - Googleマップを使用したアクセス情報を表示
- **FOOTER**
  - 店舗情報
  - ページ内リンク
  - SNSリンク

## 使用技術

- HTML5
- CSS3（Sass / SCSS）
- Google Fonts
- Google Maps（埋め込み機能）

## 工夫した点

- **視認性を意識した配色**
  白を基調に、ブラウンやベージュを取り入れました。文字が読みやすく、カフェらしい落ち着いた印象になるように配色しています。
- **AI生成写真を活用したデザイン**
  サイトのトーン＆マナーに合わせて画像生成AIで作成したオリジナル写真を使用し、商品の魅力や店内の雰囲気を視覚的に表現しました。
- **情報を整理したレイアウト**
  店舗紹介、メニュー、アクセス情報をセクションごとに分け、ユーザーが必要な情報を探しやすい構成にしています。
- **ページ内リンクの実装**
  ヘッダーとフッターにページ内リンクを設置し、各セクションへスムーズに移動できるようにしました。

## 注意事項

- このWebサイトは、ポートフォリオ掲載を目的とした架空のカフェサイトです。
- 記載している住所、電話番号、営業時間、価格などは実在の店舗情報ではありません。
- サイト内で使用している写真は、すべて画像生成AIを使用して作成したオリジナル画像です。
